# WirePack — математическая модель геометрии

**Версия:** 0.1  
**Статус:** Черновик

## 1. Общая модель

Задача WirePack заключается в поиске компактного расположения заданного набора проводов внутри круглой защитной трубки.

Для геометрических расчётов:

- Каждый провод представляется кругом.
- Защитная трубка представляется внутренней окружностью.
- Все размеры задаются в миллиметрах.
- Геометрические вычисления выполняются с использованием `double`.

## 2. Математическая модель провода

Каждый провод задаётся следующими параметрами:

- Наружный диаметр \(d_i\).
- Радиус \(r_i = d_i / 2\).
- Координаты центра \((x_i, y_i)\).

Геометрическое положение провода определяется координатами его центра и радиусом.

## 3. Математическая модель защитной трубки

Защитная трубка представляется окружностью с параметрами:

- Координаты центра \((c_x, c_y)\).
- Внутренний радиус \(R\).
- Внутренний диаметр \(D = 2R\).

Положение центра защитной трубки является переменной расчёта.

Толщина стенки трубки не учитывается.

## 4. Условия допустимости компоновки

### 4.1. Отсутствие пересечения проводов

Для любых двух различных проводов \(i\) и \(j\) расстояние между их центрами должно быть не меньше суммы радиусов:

\[
(x_i-x_j)^2+(y_i-y_j)^2 \geq (r_i+r_j)^2
\]

Равенство соответствует касанию проводов.

### 4.2. Размещение проводов внутри трубки

Каждый провод должен полностью находиться внутри внутренней окружности защитной трубки:

\[
\sqrt{(x_i-c_x)^2+(y_i-c_y)^2}+r_i \leq R
\]

Равенство соответствует касанию провода внутренней стенки трубки.

### 4.3. Численный допуск

При проверке условий 4.1 и 4.2 применяется численный допуск \(\varepsilon > 0\), учитывающий погрешность вычислений с `double`.

- Касание проводов друг с другом и со стенкой трубки считается допустимым.
- Конкретное значение \(\varepsilon\) определяется при реализации геометрического ядра и проверяется автоматическими тестами.

## 5. Целевая функция

Основная цель расчёта — минимизация внутреннего диаметра защитной трубки:

\[
D = 2R \rightarrow \min
\]

Для заданного расположения проводов минимальный радиус охватывающей окружности определяется как:

\[
R = \min_c \max_i \left( |p_i - c| + r_i \right)
\]

где \(p_i\) — центр провода \(i\), \(r_i\) — его радиус, \(c\) — центр охватывающей окружности.

При этом должны выполняться все условия допустимости компоновки из раздела 4.

## 6. Проверка геометрической корректности

Каждая найденная компоновка должна проходить независимую проверку.

Проверяются:

- Отсутствие пересечений между всеми парами проводов.
- Полное нахождение каждого провода внутри защитной трубки.
- Корректность рассчитанного внутреннего диаметра.
- Соответствие сохранённых центра и диаметра охватывающей окружности фактическим координатам проводов.

Для проверки компоновки центр и радиус охватывающей окружности должны определяться по фактическим координатам проводов, а не приниматься без проверки из результата оптимизатора.

## 7. Численная точность

Для геометрических вычислений используется тип `double`.

При сравнении геометрических величин применяется численный допуск, учитывающий погрешность вычислений.

Значение допуска и правила его применения определяются в соответствии с разделом 4.3 при реализации геометрического ядра и проверяются автоматическими тестами.

## 8. Независимость геометрической модели от оптимизации

Геометрическая модель не должна содержать алгоритмов поиска оптимального расположения проводов.

Её задача — предоставлять геометрические операции и проверять корректность заданных компоновок.

Поиск и улучшение компоновок выполняются отдельным проектом WirePack.Optimization.
