# WirePack — требования к продукту

**Версия:** 0.1  
**Статус:** Черновик

## 1. Назначение программы

WirePack — настольное инженерное приложение для расчёта компактного размещения электрических проводов внутри круглой защитной трубки.

Программа должна подбирать геометрически допустимые варианты расположения проводов и определять требуемый внутренний диаметр защитной трубки.

Основная задача — помочь инженеру-конструктору оценить требуемый размер трубки и выбрать подходящий вариант компоновки проводов.

## 2. Решаемая проблема

При проектировании электрических жгутов и прокладке проводов в защитных трубках инженеру необходимо определить, поместятся ли провода внутри трубки и какой внутренний диаметр для этого потребуется.

Ручной подбор расположения проводов затруднителен, особенно при большом количестве проводов и различных диаметрах.

WirePack должен автоматизировать этот расчёт, находить компактные варианты размещения и наглядно отображать полученные результаты.

## 3. Исходные данные

Пользователь задаёт провода группами.

Для каждой группы указываются:

- Наружный диаметр провода с изоляцией, мм.
- Количество проводов данного диаметра, шт.

Все провода одной группы имеют одинаковый наружный диаметр.

Расчёт должен поддерживать наборы до 100 проводов.

На основании введённых данных программа формирует набор проводов для расчёта.

## 4. Геометрическая модель

- Каждый провод представляется кругом, диаметр которого равен наружному диаметру провода с изоляцией.
- Защитная трубка представляется кругом.
- Толщина стенки защитной трубки не учитывается. Рассчитывается её внутренний диаметр.
- Провода могут соприкасаться друг с другом и со стенкой трубки.
- Пересечение проводов между собой и выход за пределы внутренней окружности трубки не допускаются.
- Положение центра защитной трубки определяется в процессе расчёта и не фиксируется в начале координат. Для готовой укладки центр совпадает с центром минимальной охватывающей окружности.
- Все геометрические размеры задаются в миллиметрах.

### 4.1. Точность вычислений

- Для геометрических вычислений используется тип `double`.
- При проверке геометрических условий применяется численный допуск, учитывающий погрешность вычислений.
- Допуск применяется так, чтобы касание проводов друг с другом и со стенкой трубки считалось допустимым.
- Значение допуска определяется на этапе реализации геометрического ядра и проверяется тестами.

## 5. Результат расчёта

Программа должна:

- Определять наименьший найденный внутренний диаметр защитной трубки, необходимый для размещения всех заданных проводов.
- Находить до пяти лучших различных вариантов расположения проводов.
- Для каждого варианта отображать геометрическое расположение проводов и рассчитанный внутренний диаметр трубки.
- Не выдавать найденный результат за доказанный глобальный оптимум. Если глобальная оптимальность не доказана математически, результат считается лучшим найденным вариантом.

Результаты расчёта отображаются графически непосредственно в интерфейсе программы.

### 5.1. Различие вариантов компоновки

Два варианта размещения считаются одинаковыми, если один можно получить из другого посредством:

- Параллельного переноса всей компоновки.
- Поворота всей компоновки.
- Зеркального отражения всей компоновки.
- Перестановки проводов одинакового диаметра.

Сравнение вариантов выполняется с учётом численного допуска, согласованного с допуском геометрических вычислений.

В результатах должны отображаться только геометрически различные варианты.

### 5.2. Управление расчётом

- Пользователь может остановить выполняющийся расчёт.
- При остановке сохраняются и отображаются лучшие найденные к этому моменту варианты компоновки.
- Расчёт ограничен 60 секундами с момента запуска оптимизации.
- По истечении 60 секунд расчёт автоматически останавливается; лучшие найденные варианты сохраняются и отображаются.
- Если достигнут критерий достаточности, определённый в `optimization.md`, расчёт завершается раньше 60 секунд.
- При одинаковых исходных данных результат расчёта должен быть воспроизводимым. Исключение — срабатывание аварийного 60-секундного таймаута.

## 6. Сохранение проекта

Программа должна поддерживать сохранение проекта в файл и открытие ранее сохранённого проекта.

Проект должен содержать версию формата данных, исходные данные проводов и результаты расчёта.

## 7. Запуск расчёта

Расчёт запускается одной кнопкой «Рассчитать».

Параметры алгоритма оптимизации пользователь не настраивает. Программа самостоятельно выбирает необходимые параметры расчёта.

## 8. Поддерживаемые платформы

- Разработка программы ведётся в Ubuntu.
- Программа должна поддерживать работу в Ubuntu и Windows.

## 9. Критерии приёмки

Первая версия программы считается готовой, если:

1. Пользователь может вводить группы проводов с разными наружными диаметрами и количеством; расчёт поддерживает наборы до 100 проводов.
2. Программа находит допустимые варианты размещения без пересечения проводов и выхода за границы трубки.
3. Для каждого найденного варианта определяется внутренний диаметр трубки.
4. Найденные варианты отображаются графически в интерфейсе программы.
5. Пользователь может остановить расчёт без потери уже найденных результатов.
6. Проект можно сохранить в файл и повторно открыть.
7. Программа находит до пяти геометрически различных вариантов, если они существуют.
8. Программа не выдаёт найденный результат за доказанный глобальный оптимум.
9. Проект открывается с проверкой версии формата и корректности данных.
10. Программа работает в Ubuntu и Windows.
11. Расчёт для 100 проводов завершается не позднее чем через 60 секунд; при досрочном завершении результат отображается раньше.
12. При автоматической остановке по таймауту сохраняются и отображаются лучшие найденные результаты.
13. При одинаковых исходных данных результат расчёта воспроизводим, кроме случая срабатывания аварийного таймаута.
