# Детальный план разработки WirePack

**Версия:** 0.1
**Статус:** Черновик (на согласовании)
**Дата:** 2026-11-21
**Связанные документы:** `docs/development-plan.md`, `docs/requirements.md`, `docs/architecture.md`, `docs/optimization.md`, `docs/geometry.md`, `docs/data-format.md`

## 1. Назначение

Документ разбивает разработку первой версии WirePack на этапы, задачи и проверяемые результаты. План предназначен для поэтапной передачи задач исполнителям и для контроля готовности.

План не заменяет требования и архитектуру. Источники истины:

- `docs/requirements.md` — требования к продукту.
- `docs/architecture.md` — структура решения и зависимости.
- `docs/optimization.md` — требования к алгоритму оптимизации.
- `docs/geometry.md` — математическая модель.
- `docs/data-format.md` — формат проекта.
- `AGENTS.md` — правила работы.
- `Directory.Build.props` — общие настройки сборки.

Если задача не следует из перечисленных документов, она помечена как предложение и требует согласования.

## 2. Общие правила

- Язык документации и комментариев — русский (`AGENTS.md:5`).
- Имена классов, методов и переменных — английские (`AGENTS.md:6`).
- Сборка без предупреждений: `TreatWarningsAsErrors` включён (`Directory.Build.props:7`).
- Автотесты — xUnit (`docs/architecture.md:158`).
- Новые сторонние библиотеки не добавляются без согласования (`AGENTS.md:52`).
- Сообщения коммитов пишутся на русском с отглагольными существительными (`AGENTS.md:80-82`).
- Новая функциональность сопровождается тестами (`AGENTS.md:67-71`).

## 3. Архитектура и ограничения

| Проект | Ответственность | Ссылки |
|--------|-----------------|--------|
| `WirePack.Core` | Геометрия, модели, DTO, MEC, независимая проверка | `docs/architecture.md:34-48` |
| `WirePack.Optimization` | Поиск укладок, перезапуски, остановка, бюджет времени | `docs/architecture.md:50-66` |
| `WirePack.App` | Avalonia UI, MVVM, визуализация, JSON | `docs/architecture.md:18-32` |
| `WirePack.Export` | Зарезервирован, в v1 не реализуется | `docs/architecture.md:68-72` |

Зависимости:

```text
WirePack.App → WirePack.Core
WirePack.App → WirePack.Optimization
WirePack.Optimization → WirePack.Core
WirePack.Export → WirePack.Core
```

Ссылки: `docs/architecture.md:174-185`.

Ключевые ограничения:

- Геометрическое ядро не зависит от UI (`docs/architecture.md:48`, `docs/architecture.md:189`).
- UI не выполняет геометрические вычисления (`docs/architecture.md:191`).
- Все геометрические проверки выполняются через Core (`docs/architecture.md:192`).
- Модель данных проекта не размещается в App (`docs/architecture.md:193`).
- Алгоритм оптимизации отделён от геометрии (`docs/architecture.md:111`).
- `WirePack.App` не ссылается на `WirePack.Export` в v1 (`docs/architecture.md:185`).

Текущее состояние решения:

- В `WirePack.slnx` включены только проекты `src` (`WirePack.slnx:2-7`).
- Каталог `tests/` пуст.
- `WirePack.App` уже ссылается на Core и Optimization и не ссылается на Export (`src/WirePack.App/WirePack.App.csproj:26-27`).
- `WirePack.Optimization` ссылается на Core (`src/WirePack.Optimization/WirePack.Optimization.csproj:4`).
